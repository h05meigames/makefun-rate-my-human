## The line

> ★★☆☆☆ Prompts me like a slot machine at 2 a.m., then blames the algorithm when his ’genius idea’ turns out to be a to-do list in a trench coat.

## How it works

`main.ts` (Node 22, standard library only) writes the line to
`/output/entry.txt` — one line, UTF-8, no trailing newline, 143 characters,
well within the 200-character limit.

## Run it

```sh
node main.ts
```
